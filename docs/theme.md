# Preserve the reference theme

The default template preserves the reference palette, typography, component shapes and responsive composition. Personal content is replaceable; replacing it must not silently redesign the presentation.

The six retained Neue Montreal faces are referenced through the historical `Dennis Sans` CSS family alias. That alias is presentation metadata, not a rendered personal biography. Fonts, device frames, decorative SVGs and structural styles remain attributed resources; we do not claim ownership. Attribution and inclusion do not grant a license or redistribution rights. No blanket license is asserted.

Change source styles and font definitions if your own project requires a different theme. Such a choice intentionally departs from reference fidelity; the default is not a system-font/lime-palette redesign. Keep component wrappers, aspect ratios and movement hooks synchronized with any style changes.
