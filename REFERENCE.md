# Design provenance

The visual and motion reference is [Dennis Snellenberg / Code by Dennis](https://dennissnellenberg.com/). Retained structural CSS remains attributed to its original creator. Public availability and technical separation do not establish a reuse license or ownership transfer.

## Retained presentation

The template uses fictional content and ordinary React components. Original personal identity, project photographs/videos, captured HTML, analytics and original scripts are not part of the current application. Six font files, structural CSS, generic device frames and decorative SVGs remain as presentation assets. Flat gray placeholders replace personal media; historical font aliases and class hooks are presentation metadata, not visible identity.

The design and retained resources are reference-derived. No blanket MIT license or third-party ownership transfer is asserted. Assess applicable rights before redistribution or public deployment, and preserve existing attribution.
